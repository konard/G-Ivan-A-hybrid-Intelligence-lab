# Открытые вопросы `M4` и сводка по конвейеру

## 1. Что модуль утверждает и чего не утверждает

**Утверждает.** Маршрут — предварительное обязательство с семью инвариантами;
оси назначаются на `HG-0` с обоснованием; конфликты разрешаются в сторону
строгости; состояние работы должно быть полностью выводимо из контрактов;
право остановиться (`HG-8`) обязано существовать.

**Не утверждает.** Что накладные расходы маршрутного листа приемлемы для мелких
работ. Что `axes_basis` не выродится в формальность. Что пошаговый режим сегодня
действительно пошаговый.

## 5. Сводка по конвейеру `M1`–`M4`

Порядок внедрения, вытекающий из зависимостей дельт всех четырёх модулей, **не
совпадает** с порядком слоёв:

| Шаг | Дельты | Почему первым |
| --- | --- | --- |
| 1 | `Δ4.1`, `Δ4.2`, `Δ4.6`, `Δ3.1`–`Δ3.4`, `Δ3.9`, `Δ2.4` | делают видимым то, что уже происходит; не меняют работу |
| 2 | `Δ1.1`, `Δ1.2`, `Δ1.6`, `Δ2.1`, `Δ2.2` | идентичность и обоснованность элементов — фундамент всех проверок |
| 3 | `Δ2.3`, `Δ2.7`, `Δ1.3`, `Δ1.4`, `Δ1.5` | закрывают наблюдаемые боли (тендерные формы, состав ядра) |
| 4 | `Δ4.3`, `Δ4.4`, `Δ4.9`, `Δ3.5`, `Δ3.6` | вводят оси, маршрут и длинный горизонт обратной связи |
| 5 | `Δ2.5`, `Δ2.8`, `Δ4.5`, `Δ4.7` | веер, разделение решений, прерывания и остановка |
| 6 | `Δ1.7`, `Δ1.8`, `Δ2.6`, `Δ2.9`, `Δ3.7`, `Δ3.8`, `Δ4.8` | самое дорогое: полный набор моделей, шаблоны, метрики элемента |

**Главный вывод конвейера.** Первые два шага не требуют ни одного нового
процесса — только фиксации того, что уже решается молча. Это и есть ответ на
риск, общий для всех четырёх модулей: конструкция из девяти гейтов, пяти
контрактов и шести осей внедряема только если начинать с бесплатной части.

## 7. Глоссарий модуля

| Термин | Значение в `M4` |
| --- | --- |
| Маршрут | предварительно объявленная последовательность слоёв, гейтов и проверок |
| Маршрутный лист (`C-RK`) | машиночитаемый артефакт маршрута с осями, владельцами и состоянием |
| Типовой маршрут (`RT-A`…`RT-F`) | преднастроенная комбинация осей для класса работ |
| Прерывание (`IN-*`) | приостановка с сохранением состояния в контрактах |
| Эскалация (`ES-*`) | добавление со-решающего к владельцу гейта |
| Право остановки (`HG-8`) | явная возможность прекратить работу без поставки |
| Телеметрия (`TL-*`) | источники данных о стоимости работы |
